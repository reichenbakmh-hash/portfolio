# Portfolio — Daniel Gracy Razafinjaka Rabary

Portfolio en 3D : une scène WebGL (Three.js) dans laquelle l'écran de l'ordinateur affiche le site complet (`static/os/`).
Sur mobile ou sans WebGL, le visiteur est redirigé directement vers cette version 2D.

## Développement

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
```

Le site généré se trouve dans `public/`.

## Contenu du site

Le contenu affiché sur l'écran se modifie dans `static/os/` (`index.html`, `styles.css`, `script.js`, `pic/`).
